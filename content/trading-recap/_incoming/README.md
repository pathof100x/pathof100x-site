# _incoming (chart drop folder)

Drop your TradingView chart screenshot(s) here, then tell Claude "the chart is ready."

- Save the PNG here (any filename is fine, e.g. `mnq-jul-13.png`).
- Claude moves + renames it into the recap's page bundle as `featured.png` (which becomes both the in-post chart and the card thumbnail).
- This folder starts with `_` and is set to never render, so nothing here is ever published.

Once a chart has been placed into its recap folder, the file here can be deleted.
